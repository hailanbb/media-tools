# MediaFlow 外文发行名误报与同一 TMDB 多目录复核方案

2026-11-12 · 核查版本 v2.5.17（1dabbd2）。适用于各剧集初检目录。建议将文件名中的发行片名用于解释作品别名，把实际存在的作品目录用于判断重复目录。三个韩国剧集案例均可在原 TMDB ID 下得到解释。

## 韩国剧集现场核查

最近一条源路径包含“韩国剧集”的本地任务保存了 20 条季记录，19 条处于 identity_review，其中 17 条是本地 S01 而提示“仅收录 S01”。这是排查旧记录的范围，不能据此断定 19 条全部误报。

| 案例 | 原目录 ID 的 TMDB 英文详情 | 建议重新初检后的处理 |
|---|---|---|
| Boss的甜蜜诱惑 S01，1/12 | 326975 的英文名正是 What a Boss Wants，韩国，2026 年首播 | 撤销发行名冲突。按现有未确认播毕的记录和 1/12 覆盖，预计回到连载留源。 |
| 不是你的恋爱 S01，14/14 | 314939 的英文名正是 A Love Other Than Yours，韩国，2026 年首播 | 当前记录标记已播毕、无重复。重新核实 14 个有效集号、归档目标及其他正常门槛后，可进入齐全可归档。 |
| 不着边际的你 S01，6/16 | 334517 的英文名为 Oh! My Guard，与发行名 Oh My Guard 只差标点。误推的 120847 是 2017 年菲律宾作品 OMG: Oh My Guardians | 排除 120847。候选恰好有 6 集与本地已有 6 集无关。按现有未确认播毕状态，预计回到连载留源。 |

只读列取源库和归档库的“电视剧/韩国剧集”分类，两端分别核对作品目录名称：上述三个 ID 在源端各有一个目录，归档端该分类没有对应 ID 的目录。页面打印的归档目标是预期路径，不能作为归档目录已经存在的证据。此观察范围不包含其他分类或挂载。

参考条目：[What a Boss Wants](https://www.themoviedb.org/tv/326975)、[A Love Other Than Yours](https://www.themoviedb.org/tv/314939)、[Oh! My Guard](https://www.themoviedb.org/tv/334517)、[被误推的菲律宾作品](https://www.themoviedb.org/tv/120847)。

## 当前误报是怎样产生的

在 app/core/inspector.py 中，未配置单季映射时也会调用 _investigate_season_identity，即使主 ID 已收录所选季。遇到被认定“不兼容”的发行片名，搜索候选时又排除了主 ID。没有其他候选时，提示还能把提取出的发行名原样填回“高度对应”；有候选时则可能拿搜索第一项作参照。前两例的提示没有给出另一个作品 ID，第三例给出的候选与原作地区、年份均不同。

另一个入口在 app/core/identity_resolver.py：两个不同的规范化发行名即可触发 mixed_works；已配置映射的分支同样会检查该标记。单纯增加英文别名表只能缓解部分案例，还需修正这两处触发条件，以及最终覆盖正常初检结论的优先级。

## 建议的判定顺序

1. **目录有显式有效 ID，当前季属于该作品。** 按主 ID 和季号核对播出状态、正片、重复、归档覆盖。中文、韩文、英文、旧译名、发行别名、标点差异，乃至一个季内有多种标题写法，都不能单独触发改绑、混放或人工复核。原名、英文显示名、翻译名和别名按 ID 缓存，忽略大小写、全半角、空白及常见标点，仅用于说明。未找到别名也无需发起跨作品模糊搜索。
2. **当前季未收录或已有明确的季映射。** 优先复用已核实的本地季／资料季映射。如《极地恶灵》本地 S03 对应独立条目 S01，应继续按 6 集核对。资料源超时显示“本次资料查询未完成”。已成功取得季表却缺少该季时，可提示“当前季表未收录 Sxx”；不得据此宣称该季不存在。
3. **保留真正错放的识别能力。** 例如 Gravesend S08 同时有主作品未收录 S08、多个文件指向另一作品、多个独特分集标题逐集吻合，可提示“疑似错放”并展示对应文件。Kingdom 等共用名称只有季号矛盾时，请核对季号并将候选列为线索。若文件有可信的外部作品 ID 且与目录 ID 明确矛盾，单独列出证据。文件数量、候选搜索排名及多个不同语言标题都不能单独作证。
4. **目录缺少 ID、ID 无效或不可查询。** 沿用名称、年份、季号等辅助识别；区分 ID 未识别、查询暂时失败及存在多个同名候选。自动发现不能静默改写目录绑定。

## 哪些多目录情况应交给用户

按“同一作品 ID、实际存在的作品级目录”建立索引，同时保存源／归档侧、分类、规范路径、原目录名、季号和覆盖集号。使用存储提供的稳定标识（若可用）排除同一目录重复枚举。Season 1、Season 2 属于同一作品目录的子目录。先对本次源分类及对应归档分类完整列取，在界面标明覆盖范围；跨分类检查可复用其他任务的目录索引，提示前重新核实路径仍存在。

| 实物情况 | 建议行为 |
|---|---|
| 一个源作品目录，归档目标仅被计算出来 | 正常检查；不生成重复目录记录。 |
| 源与归档各一个，同 ID、同目录名 | 正常比较两端覆盖。已有部分归档是正常工作状态。 |
| 源或归档同一侧，同 ID 对应两个以上独立作品目录 | 一张“同一作品有多个目录”卡列出所有路径及季覆盖。即使两目录分别只有不同季也提示一次，不按季重复刷屏。 |
| 源与归档各一个，同 ID、目录实质异名 | 按本次偏好进入一次“同 ID 异名目录”人工确认，显示实际路径、各自季号和已有集。可能是改名或别名；原因不宜断言。用户可选现有归档目录为后续目标，或标记两目录有意共存。 |
| 只改过显示名，磁盘上仍只有一个目录；或仅标点、大小写显示不同但实际是同一个目录 | 不提示。不同物理目录即使名称规范化后相同，仍须按实际目录核对。 |
| 多个 ID 不同、作品同名 | 分别按 ID 处理，不按标题合并。 |

优先复用现有“待复核清理”，目录卡的主要动作是“查看目录／确认归档目标”。确认前暂停涉及该组的自动合并、归档和源端删除。用户打开卡片、确认目标或保留别名都不应触发文件移动或删除。确认记录绑定 ID、库、实际路径集合与目标；新增路径、目标消失或绑定 ID 变化时再提示。原有唯一别名自动匹配和“删除源端（本季）”也要经过同一确认规则，防止其他入口绕过。确认后仍执行实际文件覆盖检查。

## 实施与验收

先改身份判定与提示文案，再增加同 ID 目录索引和组级确认。最后提供“重新评估本任务归属提示”：只读重算受影响季，保留原诊断以便比对。旧 identity_review 可能清空缺号或覆盖其他状态，应重新计算两库覆盖、重复及播毕情况；仅去掉页面标签会造成状态和计数错误。保留已手动处理记录和已确认映射，复评不启动补缺、移动或删除。

- 三个现场样例和未预设的外语剧名均测试；屏蔽英文别名接口后，只要主 ID 与季号仍已核实，不能因缺少翻译而重新报冲突。
- 同季双语命名不触发 mixed_works；真实文件 ID 冲突、Gravesend S08 多项证据错放、Kingdom S06 同名歧义及《极地恶灵》跨条目映射均保留各自结果。
- 分别构造两端同名、两端异名、一侧多目录、目标路径不存在、同 ID 多季及确认后出现第三目录。检查卡片次数、可执行操作及确认失效行为。
- 在原韩国剧集任务先输出复评前后对照，逐条列出仍需人工处理的独立证据。验收以消除仅由发行名触发的误报、保留真实异常、任务卡数量与明细相符为准，不预设全部 19 条都应移出。

## 联动影响与分步上线条件

以下条件细化前文的实施顺序。第一批只修复“目录主 ID 已核实且收录本季，仅因外文名不同而拦截”。第二批单独处理同 ID 多目录确认，可独立启停和回退。上线前先在任务副本运行新旧规则，用同一份源、归档和元数据快照对照，避免把两次扫描之间的新入库误算成规则变化。

| 受影响入口 | 应允许的变化 | 必须验证的边界 |
|---|---|---|
| 任务卡、明细、全选及批量操作 | 误报季按完整初检结论回到连载、归档、补缺或原有复核类别 | 同步更新状态、冲突原因、缺号、重复号和汇总。核对按钮与后端许可一致；打开页面、刷新或复评不会发起移动、删除、下载。旧页面提交时重新检查当前状态及目标。 |
| 归档、重复清理、删除源季或整剧 | 已核实身份后可以重新评估操作资格 | 每个写入口仍使用本身的实物校验。特别验证“归档已齐 → 删除源端（本季）”按实际归档覆盖决定，不能由解除归属冲突直接赋权。目录选定之前禁止批量写入歧义路径。 |
| MP 补缺及已推送待入库 | 重算后确有缺集的季可回待办 | 对照实际缺号、队列及持久化受理记录，全选结果排除已覆盖项。改判发行名不会清空下载回执或重新提交同一资源。 |
| 用户映射及撤销 | 保留已确认的对应关系 | 撤销映射时按新规则及当前证据重判。旧记录保存的 previous_conflict 可能就是误报，直接恢复它会让同一问题重现。真实错季和跨条目季映射继续用既有案例回归。 |
| 退订并清源 | 单纯的译名纠正不改变订阅或源路径 | 多目录治理会影响路径选择。预览与执行都要检查所选物理路径、候选集合是否变化及原确认范围；出现新目录时重新预览，避免沿用过期授权。 |

第二批需显式验收一个行为取舍：既有流程可以对唯一的同 ID 异名归档目录核实覆盖后提供清源。改为目录组确认后，首次会多一次人工确认，确认只记录路径关系；同组后续季复用，目录集合变化再提示。按具体操作判断阻断范围，单纯归档命名差异无需撤销可靠的下载回执。

发布前逐条检查韩国任务 20 条记录的去向和操作资格，重点保留原先正常的那一季作为对照；另对欧美错季、综艺分段、补缺已受理、同 ID 异名归档做隔离回放。验收要求为：预期变化可解释，无关样本的归属、可执行操作及已有受理状态一致，复评过程媒体写入和 MP 提交次数均为零。出现无关差异便暂停扩大范围，记录触发样本。保存受影响记录的前后差异和规则版本，回退时仅恢复没有后续用户操作的诊断字段；已产生的外部操作单独对账。
