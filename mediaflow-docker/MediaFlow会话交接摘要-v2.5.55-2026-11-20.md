- 同 ID 规范目标唯一时自动选择或新建，普通更名仅统一有效 SxxE… 前缀；字幕同步，迁移后核验，实际空目录才回收。
- 正常条目无需人工确认；异常只保留具体身份、季资料、期段、读取或执行问题。移除无明确用途的更多菜单及“已手动处理”，本次保留可恢复且不算成功。

- 豆瓣查询失败不等于网站无资料。绑定复用、搜索及网页兜底已加入代码；总数不证明播毕，候选集数不能证明当前文件属于候选。
- 动漫规则优先从最近有效分类路径建立默认值，可由有效人工设置及可信资料修正；缺集卡不显示“非动漫（自动）”标签。
- 用户后续已修改早期“缺集模块不删源”的约定：允许单季独立“主动放弃补缺并删除源端”，必须预览和明确确认，不纳入自动推荐或批量删源，不等同于归档安全清源。

## 本会话代码修复

### v2.5.53 及后续预览修复

- 同作品拼音／中英文别名桥接，特别节目、会员版和日记等识别保护；少量相邻扩展集号在身份、播毕、正片覆盖成立时保留，不直接判错配。新增 `pypinyin` 依赖须安装。
- 豆瓣空媒体对象不按默认“电影”误排除；查询结果与原始错误分层展示，详情读取采用受限并发。
- 推荐副本清理预览强制读取目录，避免旧缓存与执行前强读不一致造成循环。
- 暂停页按季摘要，差异字段区分大小、文件标识和修改时间，文件清单与完整路径分层折叠；读取失败不冒充视频变化，暂停时清除旧统计。

### v2.5.54 执行与事务修复

- 补缺复查保留人工绑定／缓存读取，设置 `persist_metadata=False`，避免检索前缓存写入触发长事务。
- 多个外部等待前结束事务；异常回滚；SQLite 连接配置 WAL、30 秒锁等待。提交意图与回执仍分阶段保存，不自动重试整个下载提交链。
- 补缺 API 返回中文故障说明和错误码，完整异常留服务日志。
- 作品季数与目录组数分开显示，清源成功数为 0 时不再假报源端已清理。
- 新增 `app/core/auxiliary_inventory.py`：只对“合并保留”目录有界递归强读验证，当前仅允许 NFO、图片、TXT 等列明附件；视频、STRM、未知类型、读取失败或越界不能按纯附件忽略。该标记只影响识别，不授权删除。

### v2.5.55 整季包回退

- 原有策略保留：缺集 >3 优先合格整包；≤3 优先散集，散集补不齐时回退合格整包。**只缺 1 集也允许下载整季**，不能要求包内每集都为缺号。
- 修正按期综艺无文件清单时的一律拒绝：无已知分段冲突时，允许明确“全 N 集／期”或总数一致的 Complete 声明。具体文件清单优先，已知分段、残缺清单、错季和总数冲突继续核验。
- 整包继续满足站点、做种、画质、语言和在途去重条件，已有文件及整理历史不因重复下载而删除。
- 日志区分全部候选最高做种与覆盖合格资源做种；部分低做种不再与其他高做种但覆盖冲突候选混为一谈。
- 《Escape》候选标注 10 集、本季记录 25 集仍是覆盖口径冲突，未证明当前总数或资源哪一方错误，不能凭 223 人做种直接放行。
