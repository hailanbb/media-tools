# 剧集归档：详细需求与业务规则

文档基线：1.3 · 关联需求：A-01～A-13、G-01～G-14、X-11～X-22。

## 1. 目标与归档单位

将已播完、内容与目标版本完整、通过复核的季移入既定归档位置，保护已有目标内容和仍留源的其他季。归档记录必须能说明移动了什么、保留了什么、哪些尚未完成。

**默认支持按完成季增量归档，保留显式整剧模式。**这替代 1.2 默认要求整部源剧目录所有实际季一起满足条件的限制。初检先核对同一收藏的多目录及各季，归档计划明确模式、所选季、物理操作单元和保留项。旧报告没有模式时需补充确认，不能用当前默认值静默赋予移动范围。

| 模式 | 资格与范围 |
| --- | --- |
| 按季归档 | 选择已满足条件的季；其余季及所需资料留源。其他季独立的缺集/连载不阻挡所选季 |
| 整剧归档 | 全部关联源目录的所有实际季、根资料、特殊内容均核实且可迁移，才可计划整体移动 |

不要求节目永久完结，不强制补齐未收藏的季，不把“当前已播齐全”当作“全季已完成”。按季模式也不默认归档未齐全半季。

## 2. 典型状态与分流

| 实际情况 | 归档与后续处理 |
| --- | --- |
| S01 完整已播完；S02 连载中 | S01 可单独归档；S02 留源继续更新 |
| S01 完整；S02 已播完但缺 E03 | S01 可单独归档；S02 留源，先核对别名目录与已有任务，再补真缺集 |
| S02 登记 12 集，已播 8 集且已有 8 集 | 当前已播齐全，但全季未完成；留源等待，不归档半季 |
| 同季在 A/B 目录互补，聚合为完整目标版本 | 形成逐文件归并/归档计划；允许直接合入归档目标，避免先搬到源主目录再搬一次 |
| 并集齐全但版本混杂、重复未定或身份不明 | 该季留源复核，不因数量或并集齐全放行 |
| 已归档同收藏目标包含部分本季，源端是剩余互补内容 | 全季应有集合、版本与冲突核对通过后，可增量合入；源与目标位置分别留证 |
| S02 有独立的未决任务，S01 可证明不受影响 | 可单独处理 S01；相关写入可能涉及同一文件/根资料时先协调，不能假定隔离 |

未齐全季的补缺、等待和待核实规则见 [初检](02-剧集初检详细需求.md)、[补缺](03-补缺下载详细需求.md)及 [12 专项](12-同剧多目录与分季归档专项需求.md)。

## 3. 范围与资格检查（A-01、A-02）

先建立同一收藏的完整关联视图：作品身份、中文显示名与原名、已关联源/目标目录、各目录中的逻辑季、编号体系、文件覆盖、版本及必要配套。读取范围用于发现遗漏和共享依赖，不自动变成可移动范围。

所选季须逐项满足：

1. 来源、媒体类型、作品 ID、收藏范围和季/分部/剧集组映射可信。
2. 本季应有集合、已播完依据有效；经核实的文件覆盖符合目标版本策略；本地超 TMDB 范围时已按既定规则经 MP 完成豆瓣复核。
3. 本季所有关联目录已完成必要核对，没有未知视频、缺失文件、临时文件、未决请求或未解决重复影响保留完整性。
4. 本季物理文件和附件可与其他季安全区分；合并/分段/跨季文件不被强行拆分或整体误移。
5. 源目标路径、目录映射、存储边界与不覆盖约束有效，目标冲突已处理。
6. 对本季和其共享资料的外部写入已协调；本工作流的锁不能被当作对外部 MoviePilot 所有任务的全局控制。

绿色只是进入预检的提示，不能跳过上述事实检查。

### 3.1 其他季的问题是否阻挡

| 问题 | 阻挡范围 |
| --- | --- |
| 其他季独立缺集、连载或独立未知播期 | 保留该季，不因此阻挡已完成季 |
| 无法核实整部作品身份、同 ID 目录互相矛盾 | 影响该作品相关计划，先核实身份 |
| 未知文件可能属于所选季、关联目录读取不完整 | 无法排除对所选季的影响，暂缓所选季 |
| 能明确独立保留的其他季附件/特殊篇 | 标为预期留源，允许所选季计划继续 |
| 跨季合并文件、共享资料关系或写入范围不明 | 阻挡受依赖影响的季；必要时整项暂缓 |

一逻辑季可以对应多个物理 Season 目录；报告主表只保留该收藏/编号体系的一个逻辑季结果，目录和文件为明细。真实重复记录与合法的一对多关系要分别识别。

## 4. 目标路径与冲突（A-03～A-07）

源/目标根必须不同且非包含关系，归档分类和存储映射明确；不隐式创建缺失分类。主目录以可信作品/收藏绑定确定，显示名变化不临时重拼路径。日/韩/繁体目录的中文化只作为显式治理选项，不能仅凭翻译同名合入。

目标不存在时，计划可明确包含创建必要剧/季容器及文件迁移；这些是执行动作，预览不得创建。整剧移动只适用于显式整剧模式，不能为了移动 S01 顺带移动 S02 或剧根资料。

| 源与目标情况 | 计划 |
| --- | --- |
| 目标没有本剧，源有完成 S01 和未完成 S02 | 创建/选择已确认目标剧容器，迁移 S01，保留源剧根和 S02 |
| 目标已有同收藏 S01，源完成 S02 | 核对身份与共享资料后增量归入 S02 |
| 源 Season 1、目标 Season 01 | 识别同一逻辑季，逐文件核对；不能只凭同季目录名覆盖，也不直接断定永远无法合入 |
| 目标同季内容互补 | 只有完整覆盖、版本相容、全部冲突核查通过的具体计划可执行 |
| 同名文件内容或归属未定 | 相关计划暂缓，不用修改时间或大小猜可覆盖 |
| 目标有两个异名同 ID 目录 | 保留候选，确认主目录及收藏关系后再规划 |
| 中文同名但 ID 不同、同名文件代替目录 | 身份/类型冲突，阻挡 |
| Unicode/大小写比较接近但实际路径不同 | 记录原路径与潜在冲突，不静默改名 |

跨云移动可能实际涉及复制和删源，应依据已验证服务语义，不按方法名称作保证。未核实的跨存储操作不开放执行。

## 5. 附件、根资料与留源保护（A-06、A-09、X-21）

| 对象 | 按季归档要求 |
| --- | --- |
| 所选季专属视频、字幕、季 NFO、季海报 | 明确归属后完整列入计划，保留配套关系 |
| tvshow.nfo、剧根 poster/fanart 等共用资料 | 仍有留源季时保留原件；目标需要副本则列明不覆盖复制，不顺带搬走 |
| 公共字体、字幕包、跨季章节/附件 | 明确依赖；可安全保留/复制时列清，否则暂缓相关操作 |
| 目标已有共用资料 | 保留目标现有内容；不同内容冲突不按同名判重复 |
| 其他季与其专属附件 | 列为预期留源，不移动、不清理 |
| Specials/Extras/电影/未知资料 | 核对角色与依赖；可独立保留则留源，可能涉及所选季则先核实 |

某季归档成功不授予删除整个源剧目录的权限。源季目录收尾也需全项核验、确认为空且属于计划；没有视频但仍有字幕/NFO/未知文件时不能视为空。

全部季都已迁出后，剧根清理仍须独立核对残留与计划；不可通过递归删根掩盖未处理资料。整剧模式的共用资料清理同样只限有目标对应证据的明确对象。

## 6. 归档计划内容

计划至少包含：归档模式、收藏与作品身份、选定逻辑季、全部相关目录/原路径、编号与版本、来源/文件快照、主目录绑定、每个原→目标操作、不覆盖要求、目标原有保护清单、预期留源清单、必要资料副本、空目录收尾条件、阻挡项和批准范围。

确认时明确展示，例如：“移动 S01；S02 留源继续更新；根 NFO/海报保留；归档目标新增必要副本；不删除源剧根”。不能只显示剧名、绿色行和文件总数。

单份不可分割计划须先整体预检；若一季冲突而另一季可独立完成，可形成各自范围清楚的计划，不能执行中悄悄缩减用户批准的范围却报告全部完成。

## 7. 执行、核验与完成范围

1. 核对计划有效性、源/目标与外部在途写入，固定所选季和共享依赖范围。
2. 逐项记录意图，使用已验证的不覆盖行为执行；新增目录/副本也是计划内动作。
3. 每项后刷新并核验，比较路径、对象类型、大小和可取得的稳定属性；不能以“目标有一个视频”证明全季成功。
4. 核对本季应保留内容到位、目标原有内容未变、留源季及共用资料未被改变。
5. 全部迁移对象核实后，再做计划内的确为空目录收尾；预期留源清单不参与删除。
6. 写出逐季结果及本轮总结果，保留来源位置与目标位置关系。

| 状态 | 含义 |
| --- | --- |
| 季归档完成 | 该季所选计划及核验完成，可标该季紫色 |
| 本轮完成 | 本轮批准的所有计划完成；不等于所有季完成 |
| 收藏部分归档 | 某些季已归档，其他季仍留源补缺/等待/复核 |
| 整部收藏当前范围已归档 | 当前已明确收藏范围中的实际内容都完成，且无待处理残留；不暗示将来不再出新季 |
| 部分成功/待核实/失败 | 逐项列清实际状态，不能统一标完成 |

核验等级保留：路径/集号布局、大小及稳定属性、可选可靠内容校验。没有内容校验就不能宣传字节级无损；网络/权限错误不能当作源已不存在。

## 8. 中断、后续新增与审计

请求结果不明先核验，不盲目重移；恢复区分已完成、未完成和未知，不自动反向全量回滚。新到文件或变化的来源/编号使相关计划重评估。

S02 完成后可增量归入已绑定目标，S01 历史成功记录保留。S01 新文件又到旧别名源目录时，要比较归档内容与版本，不凭历史紫色跳过，不直接补下载或删除。

审计默认只读，按计划分为：已迁移内容、预期保留的 S02 等对象、异常残留、新增内容及核验失败。按季成功后源剧根仍存在是正常状态；不能用“整剧源路径消失”作为按季成功的必要条件。

## 9. 验收与专题关系

对应 T-A01～T-A15、T-F01～T-F09，以及 T-X16～T-X25、T-X36～T-X48 等场景。动漫专属编号与附件见 [11 专项](11-动漫整理专项需求与命名规范.md)；跨目录与中文名称识别见 [12 专项](12-同剧多目录与分季归档专项需求.md)。这些是目标验收标准，本轮未运行程序或执行真实迁移。
