# 通用安装步骤

[返回项目首页](README.md)

## 1. 准备地址和目录

| 配置 | 填写方式 | 示例（不要照抄） |
| --- | --- | --- |
| CloudDrive2 地址 | 协议 + 主机 + 端口，不含页面路径、参数或末尾 `/` | `https://cloud.your-domain.com:8920` |
| MoviePilot 地址 | 同上，第二脚本使用 | `https://mp.your-domain.com:8920` |
| 源根目录 SOURCE | 云盘中的绝对路径，下面应当是电视剧分类 | `/115/Library_incs/nas/电视剧` |
| 归档根目录 DEST | 第四脚本使用，必须与源目录独立，不能相互包含 | `/115/Library_incs/nas.finish/电视剧` |

路径不带界面上的 `Root` 前缀，也不是网页 URL。四个脚本使用同一个云盘地址与 SOURCE。目标根目录及同名分类要事先存在，脚本不会替你创建。

```text
SOURCE / 韩国剧集 / 示例剧 (2025) [tmdbid=真实ID] / Season 1 / 示例剧.S01E01.mkv
DEST   / 韩国剧集 / 示例剧 (2025) [tmdbid=真实ID] / Season 1 / ...
```

## 2. 安装 Tampermonkey

1. 从 [Tampermonkey 官网](https://www.tampermonkey.net/) 进入浏览器扩展安装页，安装后按提示允许用户脚本执行。
2. 先手动登录自己的 CloudDrive2 / MoviePilot，确认目录及下载器可用。
3. 暂停、导出并停用旧综合版或同阶段重复副本。不同阶段独立安装，不能覆盖成同一个脚本。

## 3. 安装所需阶段

| 阶段 | 配置入口 |
| --- | --- |
| ① 初检 | [安装第一脚本](docs/01-inspect/install.md) |
| ② 下载 | [安装第二脚本](docs/02-download/install.md) |
| ③ 复核清理 | [安装第三脚本](docs/03-review/install.md) |
| ④ 归档 | [安装第四脚本](docs/04-archive/install.md) |

每个阶段都按同一方法安装：打开 `.user.js` → 点击 GitHub **Raw** → 复制完整内容 → Tampermonkey 新建脚本 → 删除默认模板并粘贴 → 按该阶段安装页修改顶部配置 → **Ctrl+S**保存 → 刷新对应网站。

`@match` 填协议和主机名，**不带端口**；脚本内站点常量填完整 origin，**有端口必须保留**。HTTPS 和 HTTP 部署的协议也要一致，不要改为匹配所有网站。豆瓣相关 `@match` 保持不变。

普通安装只需对应 `.user.js`，不需要 `src`、`vendor`、npm或命令行。

## 4. 检查安装结果

看到对应阶段面板即加载成功，安装后仍不运行。没有面板时依次检查：已保存和启用、站点权限、`@match`、配置常量的协议/端口、网页是否已刷新。避免反复新建副本。

按住标题栏可拖动；点击“收起”停靠右下角，“展开”恢复原位置。各脚本单独记住布局。收起不会暂停业务任务，运行中要停止请点击“暂停”。

## 5. 升级与报告保存

1. 暂停并导出当前结果，记下自己的地址和路径。
2. 在 Tampermonkey 中编辑**同一阶段的原脚本**，用新版完整内容替换，重新填好顶部配置和 `@match`。
3. 保存并刷新。①可手动恢复进度；②③④重新导入报告，并利用各自保存的操作记录核实上次结果。

公开版没有自动更新地址，以免自动覆盖个人配置。不要清空脚本存储来重试结果不明的下载、删除或移动。浏览器休眠、后台节流、换浏览器或卸载脚本可能中断任务或丢失本机记录。
