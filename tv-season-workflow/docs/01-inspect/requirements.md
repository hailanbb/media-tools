# 第一脚本需求：剧集初检

需求整理日期：2026-10-21。对应发布版本：**v1.1.2**。

[工具首页](../../README.md) · [安装教程](../../INSTALL.md) · [操作说明](../01-inspect/usage.md) · [第二脚本需求](../02-download/requirements.md)

本文整理已经确认的需求及当前实现边界，供后续维护、回归和验收使用。操作步骤以安装教程和操作说明为准；没有将尚未实现的功能列为已交付能力。

## 1. 目标与分工

用户手动选择一个电视剧分类，按云盘显示的目录修改时间从旧到新，逐剧、逐季核对本地视频集号与来源登记集数，导出本轮报告。报告可人工维护，并作为第二脚本的输入。

第一脚本负责检查，**不移动、删除、重命名文件，不创建云端目录，不提交下载**。它不以文件数量代替集号完整性，也不以本地缺集判定电视剧尚未完结。

## 2. 输入与启动

| 编号 | 需求 |
| --- | --- |
| I-01 | 安装、刷新或恢复进度后默认不运行。用户点击开始、继续或补查后才执行对应任务。 |
| I-02 | 支持手动读取并选择分类，也支持对当前打开的一部剧单独检查。新建一轮会替换上一轮进度，应先导出旧结果。 |
| I-03 | 使用用户配置的 CloudDrive2 站点和源根目录，不扫描范围之外的目录。 |
| I-04 | 目录层次为“源根目录／分类／剧集／Season N”。优先从剧集目录提取 TMDB ID，并识别年份和季号。 |
| I-05 | 剧集与季目录按云盘显示的修改时间从旧到新处理。修改时间无法可靠解析时提示问题，不悄悄改用名称排序。 |
| I-06 | 支持暂停、继续以及本机进度恢复。恢复不自动运行，当前剧中断后继续时重新核对。 |

## 3. 文件与集号核对

| 编号 | 需求 |
| --- | --- |
| I-07 | 区分视频文件数与去重后的已识别集数；重复视频不能增加已识别集数。图片、NFO、字幕不计作视频。 |
| I-08 | 识别明确的 Season N 和常见集号格式。`麻辣教师 - S01E01 - 01.mkv` 中相同集号重复表达应识别为第1集。 |
| I-09 | 错季、合并集、冲突数字、无法识别集号及季内嵌套目录不得猜测，报告列出问题和相关文件。无法确认完整集号集合时，缺失集号保留“未确认”。 |
| I-10 | 对已确认的空季快速记录“视频文件数=0、已识别集数=0”，仍查询来源登记集数。不能因本地为空而清空来源数量。 |
| I-11 | 整剧空目录且没有可识别季目录时，不猜第一季。读取失败也不等于空目录，未知数量不能填0。 |
| I-12 | 报告分别列出已识别集号、重复集号、超范围集号问题、缺失集号、待播集号和播期未知集号。 |
| I-13 | 缺失集号排除明确待播和播期未知的集目；另保留“尚未收齐集号（含待播）”，避免把未播集当作需要下载的缺集。 |

## 4. TMDB 主查与豆瓣触发条件

TMDB 按电视剧 ID 查询具体季。返回内容必须符合当前电视剧、季号和登记集目要求，不能把全剧总集数当作某一季的数量。

### 进入豆瓣查询流程的条件

| 编号 | 触发情况 |
| --- | --- |
| I-14 | TMDB 未取得有效本季数据：例如没有可用 ID、请求失败、返回身份/季号不符、集目缺失、集号不连续或登记数量不一致。 |
| I-15 | TMDB 无法确认本季已播完，包括连载、待播、日期未知或缺少结束/季终依据。 |
| I-16 | 本地识别到的集号超出 TMDB 登记范围。例如来源登记16集，本地有第17集，需要进一步核实。 |
| I-17 | 用户点击“强制重查此季豆瓣”。绑定豆瓣链接仅保存候选，不立即发起查询。 |

TMDB 确认本季已播完须满足：所有登记集目的播出日期都早于核对日，并且全剧状态为已结束，或者本季末集带有季终标记。当日、未来或日期未知的集目不能直接作为已播完证据。

**不单独触发豆瓣的情况**：TMDB 已确认本季播完、数据有效且本地没有超范围集号时，仅本地缺集、空季、重复文件或文件名无法识别，不额外触发豆瓣。

| 编号 | 来源结果处理要求 |
| --- | --- |
| I-18 | 豆瓣支持简繁中文、韩文、英文和日文的完整标题及详情中明确列出的别名，核对年份、具体季号和唯一候选，不以模糊前缀或任意译名自动匹配。 |
| I-19 | 不同季分别识别和缓存，不把某一季的豆瓣集数用于其他季。人工绑定链接也不能绕过身份校验。 |
| I-20 | 豆瓣复核成功后按有效的本季数量重新计算；豆瓣失败时保留已经取得的 TMDB 数量、链接和诊断信息。 |
| I-21 | 来源登记数量与播完状态独立。豆瓣只有集数不代表已完结；两来源数量或状态冲突时，不直接沿用不适用的完结结论。 |

## 5. 豆瓣访问与补查

| 编号 | 需求 |
| --- | --- |
| I-22 | 先使用符合本剧本季、未过期且未与新来源证据冲突的缓存。进入查询流程不等于立即打开豆瓣网页。 |
| I-23 | 初检遇到普通限速、额度不足或访问准备未完成时，标记“豆瓣待补查”，继续其他剧集；有 TMDB 数量时保留它。 |
| I-24 | 补查必须手动点击“仅补查豆瓣待处理项”；下次可尝试时间不是自动执行时间。补查成功更新原结果，重新导出后才能在新 Excel 中看到变化。 |
| I-25 | 遇到登录、验证码或风控停止相关查询，不绕过验证。完成必要等待和人工处理后，用户确认恢复，再手动补查。 |
| I-26 | 强制重查可跳过缓存或单条失败记录，但不能绕过访问预算及风控冷却。刷新不清空额度。 |

当前实现参数属于可维护的技术默认值，不是豆瓣提供的安全承诺：页面间隔45秒；每20页休息10分钟；滚动一小时40页、24小时200页；风控通常至少冷却30分钟，页面要求更久时遵从；结果缓存已播完30天、连载/待播6小时、状态未知24小时；单条匹配或解析失败24小时内不自动重复查询。只能约束本脚本的访问，不能统计用户手动浏览或其他插件请求。

## 6. 报告、颜色与交接

| 编号 | 需求 |
| --- | --- |
| I-27 | 导出 Excel、CSV和完整JSON。Excel一季一行，面板只显示最近100项时，导出仍包含全部结果。 |
| I-28 | 只有“剧集目录”格标色。浅绿底深绿字表示本季确认播完、集号齐全且无待处理异常；浅蓝表示有本季仍在播出的证据。 |
| I-29 | 记录来源数量、来源名称、链接、查询时间、播出状态、判定依据和完整问题说明；未知不伪造成0。 |
| I-30 | 保留分类、剧名、季号、源云盘链接、剧集/季路径、TMDB ID、记录ID和报告版本，供第二脚本准确定位。 |
| I-31 | 用户可维护备注与普通实心颜色。CSV不保存颜色，后续下载使用xlsx。以前导出的磁盘文件不自动更新。 |

## 7. 体验与运行边界

- 文件列表须加载完整并稳定后才接受；短暂停留不必然是卡顿。当前非空列表稳定等待约1.8秒。
- 路径输入框未出现属于导航问题，不说明目录不存在。当前最多尝试三次；持续失败暂停当前剧，不自动跳过或记为空目录。
- 来源未查询时显示“来源未查询”，不能默认显示成“豆瓣”。
- 只核对文件名、目录列表及来源信息，不验证视频播放质量或文件内容哈希；Season 0、复杂嵌套和不明确分季交人工核实。
- 浏览器后台节流、休眠、页面结构变化和外部站点限制可能影响运行。脚本不承诺后台永久运行。

## 8. 关键验收场景

| 场景 | 应有结果 |
| --- | --- |
| 安装或刷新页面 | 面板空闲，不自动扫描。 |
| TMDB已播完16集，本地15集 | 报告缺集；不只因缺集额外查询豆瓣。 |
| TMDB已播完16集，本地识别到17 | 进入豆瓣复核流程，超范围问题保留。 |
| TMDB有效但本季尚未确认播完 | 进入豆瓣复核流程；不是直接按当前登记数量标绿。 |
| 明确Season目录为空 | 视频数/已识别数为0/0，仍尝试取得来源集数。 |
| 路径导航或文件列表读取失败 | 暂停或报告未知，不能记录为空目录。 |
| 豆瓣限速或风控 | 缓存可用则复用，否则待补查/人工恢复；不绕过限制。 |
| 豆瓣失败、TMDB已有数量 | 保留TMDB登记数量与说明。 |
| 第一季齐全已播完，但全剧还有第二季 | 第一季可标绿，第二季单独判断。 |
| 视频数量等于登记数量，但存在重复与缺集 | 不能标齐全。 |

当前本地验证覆盖核心判断、模拟页面和报告读写；不将通过自动测试等同于所有实际部署都已经端到端验证。

## 面板交互补充需求

按住面板标题栏可拖动，展开和收起状态均可移动。点击“收起”时自动停靠页面右下角；点击“展开”恢复收起前的展开位置。收起后可再次拖走，但下次点击收起仍会重新停靠。各脚本分别记住位置和收起状态，窗口缩放时避免面板超出可视区域。收起只隐藏界面内容，不暂停、启动或取消任务；点击按钮不会触发拖动。

验收：任意位置收起后停靠右下角；展开恢复原位置；缩放窗口仍可见；刷新恢复布局但不自动启动任务；拖动标题栏不触发下载或云盘操作。
