# ④ 剧集归档 · 需求

[项目首页](../../README.md) · [安装](install.md) · [使用](usage.md)

| 项目 | 规则 |
| --- | --- |
| 输入 | 导入含绿色项的报告，只排队；点击开始/继续检查后读取云盘 |
| 范围 | 同一剧集所有实际季必须各自唯一对应绿色行；混色、漏季、重复行、未知子目录等不能直接归档 |
| 预检 | 检查集号连续、报告数量、重复视频、文件大小及下载临时文件；目标根目录与同名分类必须已存在 |
| 新剧 | 目标分类没有同名剧集时，移动整剧目录及配套文件 |
| 同名剧 | 目标已有完全同名剧集时，移动全部季及根目录图片、NFO 等文件；目标已有标准共用资料时保留目标版本；迁移验证后删除源目录及列明的多余共用资料 |
| 同季冲突 | 目标已有同季（含 Season 1 / Season 01）或未知根目录同名文件则整剧暂缓并输出明细，不进行部分移动或覆盖 |
| 执行 | 先列清单，用户点击执行并确认后移动；每次提交前持久保存操作记录 |
| 验证 | 核对移动单元、目标原有内容，且源剧集路径必须消失；以界面路径、类型、大小和修改时间为依据 |
| 清理 | 全部内容及目标原有内容验证通过、源确认空之后普通删除源目录；删除结果不明不重发 |
| 中断 | 结果不明只读核实，不自动重复移动；保留各项已完成/未完成状态 |
| 输出 | 归档验证成功的季标紫色，冲突整剧保留原色；逐文件列出原路径、目标路径、状态及错误 |

示例：源“天龙八部 / Season 2”，目标“天龙八部 / Season 1”——把 Season 2 移入目标同名剧集。若目标已有 Season 2，则整剧暂缓并记录冲突。

不做模糊剧名合并，不创建缺少的目标分类，不覆盖同名文件，只清理当前计划内的源目录；源必须为空或只剩清单中的标准共用资料，不能含季目录、视频、未知文件或新增内容。遇到界面要求覆盖、复制或额外冲突确认时停止。


整理修复联动：报告中存在未完成修复记录时，整剧暂缓；手工绿色不能绕过该检查。
