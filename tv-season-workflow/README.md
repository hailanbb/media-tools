# 剧集整理工作流(油猴版)

一个项目，四个独立脚本，通过 Excel 报告衔接：

**① 初检 → ② 补缺下载 → ③ 复核清理 → ④ 归档**

适用于 Chrome + Tampermonkey + CloudDrive2 / MoviePilot。普通使用不需要命令行、Python、Node.js 或 AI 服务。

## 选择当前阶段

| 阶段 | 版本 | 工作网站 | 做什么 | 文档 |
| --- | --- | --- | --- | --- |
| [① 剧集初检](season-inspect.user.js) | 1.2.0 | CloudDrive2、豆瓣 | 只读核对本地集号，TMDB 主查、豆瓣按需补查，导出报告 | [需求](docs/01-inspect/requirements.md) · [安装](docs/01-inspect/install.md) · [使用](docs/01-inspect/usage.md) |
| [② 补缺下载](season-download.user.js) | 1.5.0 | MoviePilot | 读取报告，选择整季或零散资源，提交下载；检查并修复旧历史导致的整理阻挡 | [需求](docs/02-download/requirements.md) · [安装](docs/02-download/install.md) · [使用](docs/02-download/usage.md) |
| [③ 复核清理](season-review.user.js) | 1.4.1 | CloudDrive2、豆瓣 | 以豆瓣本季集数复核黄色项，确认清单后删除多余版本及专属刮削文件 | [需求](docs/03-review/requirements.md) · [安装](docs/03-review/install.md) · [使用](docs/03-review/usage.md) |
| [④ 剧集归档](season-archive.user.js) | 1.4.0 | CloudDrive2 | 确认清单后移动绿色剧集，全部内容无冲突合入，验证并清除源目录 | [需求](docs/04-archive/requirements.md) · [安装](docs/04-archive/install.md) · [使用](docs/04-archive/usage.md) |

**所有脚本默认不运行，导入报告只排队。** ② 点击开始后会提交下载；③、④先只读检查，确认具体清单后才删除或移动。建议同一云盘标签页只启用当前阶段。

下载完成但网盘仍缺集：在②点击 **检查整理问题 → 查看清单 → 修复整理 → 导出报告**，再交③复核实际文件。只适配 MoviePilot v2.15.6；详情见[整理修复使用步骤](docs/02-download/usage.md#下载好了但网盘仍缺集整理修复)。

## 第一次使用

1. 按 [通用安装步骤](INSTALL.md) 安装 Tampermonkey，准备站点地址与源目录。
2. 进入上表对应的“安装”页，填写脚本开头的配置。四个脚本的云盘地址与源目录必须一致。
3. 运行①，必要时手动补查豆瓣，导出 `.xlsx`。可人工核对、维护备注和颜色。
4. 将报告交给②，点击开始补缺下载，导出更新报告；等待 MoviePilot 实际下载和整理完成。
5. 将更新报告交给③，复核黄色项；有清理计划时，查看保留/删除清单并确认执行，再导出。
6. 将包含绿色项的报告交给④，检查并确认归档清单。移动验证成功的季标紫色，导出最终报告。

报告一季一行。运行中不要手动切换云盘工作标签页的目录；刷新或升级前先暂停并导出结果。收起面板不代表暂停任务。

## 报告颜色

只给“剧集目录”单元格标色，不给整行染色。

| 颜色 | 含义 | 下一步 |
| --- | --- | --- |
| 浅绿底、深绿字 | 本季已确认播完且齐全、无待处理异常，或人工确认 | 可交④检查归档 |
| 浅蓝底、深蓝字 | 本季仍在播出；已播部分可能缺集 | ②仍检查已确认缺集，排除待播和播期未知集目 |
| 黄底、黑字 | 已提交下载/已有任务，或等待复核、清理 | 等下载整理完成后交③ |
| 浅红底、深红字 | 当前未找到合格匹配资源或做种不足2 | 之后重查，或人工处理 |
| 浅紫底、深紫字 | 已验证归档成功 | 保留最终报告和操作明细 |
| 无填色 | 缺集、待播、来源不明或其他待核实情况 | 查看“处理结果”“核对说明” |

[报告字段与操作追溯](REPORT.md) 说明颜色代码、下载/清理/归档明细、未知值及人工维护规则。

## 重要规则

- **初检**：只在 TMDB 不可用、本季播完状态不明或本地集号超出登记范围等情况进入豆瓣流程。缓存优先；限速时待补查，到时间不会自行启动。
- **下载**：整季优先，无合格整季可补零散集；同类中文标记优先。最低2做种；同等中文条件下优先≥5做种的候选，容量均可确认时优先小容量，未知时退回做种数排序。
- **清理**：保留一个可确定的完整版本；同版本少量重复副本按云盘显示的文件修改时间选最新。多个完整版本交人工判断，不自动淘汰。
- **归档**：目标已有同名剧集时移入全部季和根目录文件；同季或未知同名文件冲突则整剧暂缓；标准根共用资料保留目标版本。无冲突时，验证已移动内容和目标原资料后，删除源目录及列明的重复共用资料；源路径消失才标紫，移动和空目录删除均记录明细。
- **界面**：四个面板均可拖动。点击收起停靠右下角，展开恢复原位置；深色站点中仍使用清晰的面板配色。
