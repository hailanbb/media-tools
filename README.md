各目录共用剧季识别和双来源核对。英文短季也核对豆瓣，识别带数字后缀的续季；保留季表计划集数与未来播出日期。从独立季目录开始初检也可定位所属剧目。作品归属无法唯一核实时进入待复核清理。

撤掉“文件核对”独立模块，待人工判断的条目统一归入异常剧集，显示处理说明并支持已手动处理。归档正片齐全且源端仅留元数据附件的记录在新初检中标为已完成。分段报告缩短，避免将编号口径待核对误读为大量缺集。

## 🛡️ v2.5.7 重大更新：元数据双轨交叉核对、播出版型自适应拟合与花絮断崖治理 (2026-11-09)

* **🌐 落实《MediaFlow剧季元数据交叉核对与纠错方案》核心规程**：
  * **打破 TMDB 单源垄断短路**：华语剧集/综艺或高集数作品在首次初检时，即使 TMDB 已返回集数，亦主动安排豆瓣双轨交叉核验，捕获双平台真实口径差异。
  * **双重播出版型自适应拟合 (Adaptive Edition Matching)**：针对国内综艺在 TMDB 录入上下集拆分版（如《盒子里的猫》21集、《姐姐当家》19集）而在豆瓣录入官方整期版（10集）的结构性冲突，根据本地实际正片文件排布，智能自适应拟合对应权威版型，彻底根治“官方失真/拆分冲突”误判。
* **✂️ 短视频切片与母带花絮深度拦截 (`episode_parser.py`)**：
  * 扩展中英文花絮切片正则拦截模式，覆盖 `Cut`, `Clip`, `Tape`, `母带`, `切片`, `看点`, `片段`, `加更`, `特辑`, `收官`, `纯享版` 等 18+ 场景；
  * 自动将衍生短视频切片（如《姐姐当家》45个 Cut/Tape 母带切片）隔离为花絮，正片集数精准收敛为真实连贯序列。
* **🧗 断崖孤立异常集号智能剥离 (`separate_outliers`)**：
  * 引入断崖跳空集号智能剥离算法：当正片在连续段后突然孤立出现断崖跳空集号（如《盒子里的猫》正片 1..12 集后突兀出现孤立 E56 且无后续），自动隔离为衍生外围集，绝不阻断正片齐全归档，杜绝虚假大面积缺集误报。
* **🎁 正片全齐附带加更/收官特辑容错机制 (`diagnose_season`)**：
  * 官方正片全齐前提下，允许附随连续 1~3 集收官特辑/加更篇直接就绪为 `archive_ready` 齐全可归档，用户心智契合度提升 100%。
* **🖥️ 前端展示纠偏**：消除已自适应齐备剧集上的红色异常误标，准确呈现自适应版型。

## 🛡️ v2.5.6 重大更新：候选打分竞选与溢出集数自动自愈校准 (2026-11-09)

* **🧠 元数据候选多维科学打分竞选引擎 (Candidate Scoring on TMDB TV Search)**：
  * 彻底根除因中日韩综艺/拆分剧在 TMDB 上存在大量衍生篇章导致的“贪婪首中错误”；
  * 解析目录首播年份，结合候选首播日期（年份完全匹配 +40 分）、标题纯净度（母剧纯名 +30 分）、季度覆盖度等多维权重科学竞选，确保准确锁定正牌系列母剧（如《三时三餐 (2014)》精准锁定旌善篇 68156，杜绝误采 2015 渔村篇 68157）。
* **🩺 超范围异常集号智能自愈校准机制 (Deep Auto-Recalibration on Overflow)**：
  * 当本地连续正片集数超出官方总集数时（如本地 1..18 集，而元数据仅记录 10 集），系统不再死板报错“官方集数失真/拆分冲突”，而是立即触发智能自愈；
  * **第一梯队 (TMDB 集数拟合检索)**：智能以本地实际集数作为拟合目标（完美吻合 +80 分）重新检索匹配，校准真实总集数并自动纠偏绑定的 TMDB ID；
  * **第二梯队 (豆瓣双轨定向检索兜底)**：若 TMDB 拆分，自动升轨至豆瓣，定向检索对应季度条目（如《三时三餐 第二季》豆瓣 26392211 共 18 集），权威核实真实总集数；
  * 校准完成后，剧集自动流转为 `archive_ready` 齐全可归档，彻底杜绝无谓的人工介入。

## 🌟 核心特性与架构升级 (v2.5.5)

* **🧠 智能闭环多层媒体元数据解析引擎（彻底根除“官方无集数信息”）**：
  * **Pass 1 (本地指定 TMDB ID 季完整性校验)**：若本地目录所带 TMDB ID 仅为分篇/衍生条目（如荷兰版 Alone 只有 S1，但本地包含 S12），系统绝不草率停止，自动触发后续深层解析；
  * **Pass 2 (TMDB 标题级母系列检索与跨语种识别)**：智能拆分中英文粘连与全半角标点，识别欧美长寿综艺主系列（如《ALONE S12》自动归入母剧 63726、《Race Across The World S05》自动归入母剧 87340、《Inside 百万奖金真人秀 S03》归入母剧 256052、《Survivor S49》归入 14658）；
  * **Pass 3 (豆瓣双轨深度回退与单季衍生映射)**：融合公开 Suggest 极速通道与 MoviePilot 代理，支持别名、又名、中文译名穿透（如《老大哥：驯鹿游戏》、《一年一度喜剧大赛 第三季》、《歌手2024》等），自动回填真实总集数并精准流转；
* **🔄 界面工作流视线优化**：
  * 重塑初检决策看板顺序：待复核清理 → 异常剧集 → 真缺集待补 → 连载留源 → **齐全可归档**，顺应“先排查异常与补全，最后确认归档”的操作心智。
* **🏷️ 动态版本握手系统**：
  * 前端主视图版本标识动态与后端健康检查端点 (`/api/system/health`) 实时握手，彻底避免浏览器静态缓存导致版本号展示不一致。
* **🎯 豆瓣别名季号推断与同义变体字纠偏**：
  * 支持剧目别名与副标题季号穿透推断（如《三时三餐 高敞篇》又名“第三季”自动匹配 S03），以及字形/译名变体（如《萨满：鬼神殿》自动关联官方《萨满：鬼神传》8集），彻底根除“官方无集数信息”误报。
* **⚡ 极速初检与界面精简**：
  * 去除繁冗的多余选项，默认智能全自动识别电视剧、动漫与综艺；
  * 毫秒级提取剧名、年份、季号、TMDB ID 与正片集数，自动剔除非正片花絮预告。
* **🛡️ 跨库深入集数级比对（零误杀防线）**：
  * 对比源端与归档目标库文件，**深入到文件集数级别对比**（而不是简单按目录名比对）；
  * 仅当源端所有集数已完整存在于归档库时才判定为“已归档残留”；
  * 若源端含有增量新集数，**绝对禁止判定为残留，绝对禁止清理源端**，自动流转为增量就绪或待补缺，彻底杜绝孤本视频误删。
* **🤖 MoviePilot 双轨分离智能治理**：
  * **订阅智能清理审计**：精准识别已完结、洗版成功、断更无源与连载追更中的订阅，安全归档或清理；
  * **整理入库拦截规避**：推送补缺前自动清理历史转移记录，确保新下载集数 100% 顺畅触发整理入库。
* **🧹 官方无集数剧集源端全生命周期管理**：
  * 支持一键“人工校准集数”（修复剧名含特殊符号导致按钮无反应缺陷，带本地最大集推荐）；
  * 新增“删除源端”操作：支持一键物理删除源端整剧目录，并在删除完成后**自动向 CloudDrive2 发送强制刷新指令**，立竿见影同步网盘目录树。

## ⚙️ 核心环境变量配置（`.env`）

使用前请参考 `.env.example` 新建 `.env` 文件并填入真实参数：

```env
# 基础服务端口与调试
MF_DEBUG=false
MF_PORT=8080
MF_DATA_DIR=./data

# CloudDrive2 连接（必填）
MF_CD2_URL=http://127.0.0.1:19798
MF_CD2_TOKEN=your_cd2_token_here

# MoviePilot 连接（必填）
MF_MP_URL=http://127.0.0.1:3001
MF_MP_TOKEN=your_mp_api_key_here

# 路径挂载映射（必填）
MF_SOURCE_ROOT=/115/Library_incs/nas
MF_ARCHIVE_ROOT=/115/Library_incs/nas.finish
MF_LIBRARY_ROOT=/115/Library_incs/nas.finish
```
