# MoviePilot订阅批量取消脚本

**版本：v2.4.0** · **环境：Chrome + Tampermonkey + MoviePilot**

通过 MoviePilot 页面上的卡片、菜单及下载确认窗口处理订阅，从页面末尾向上逐项执行。安装后默认不运行。

[安装脚本](moviepilot-unsubscribe.user.js) · [返回媒体工具](../README.md) · [原个人开发仓库](https://github.com/hailanbb/skill-selection)

---

## 🧩 功能与处理范围

| 模式 | 处理规则 |
| :--- | :--- |
| **全部订阅（当前分类）** | 从末尾逐项取消当前分类、筛选范围内的订阅。 |
| **电视剧：仅进度 0 / 总数** | 仅取消已下载集数为0且总集数有效的电视剧订阅。 |
| **电视剧：2026年前未完成维护** | 保护启动时前100张卡片，跳过2026年及之后、集数相等和自定义名单中的剧集。已下载为0时直接取消；非0时先搜索资源、确认下载任务提交成功，再取消订阅。 |

前100项保护、跳过名单、跨页下载、实时结果和维护报告适用于第三种维护模式，不能把这些保护视作前两种模式的默认行为。年份边界固定为2026年，不随当前日期自动变化。

### 维护模式如何选资源

1. 搜索对应剧名并核对年份、电视剧类型。
2. 保留站点框原有勾选项，**追加天空、观众**；馒头等原选站点仍参与比较。指定站点不存在时保留订阅并报告。
3. 在“季”菜单中仅选择目标整季，如 **S01**，不选 **S01 E01** 等单集。选项缺失或核对失败时不下载。
4. 扫描匹配的整季资源及“更多来源”。明确标注的全集数与订阅不符时排除；同名结果存在全集数冲突时，只选可确认总集数匹配的资源。
5. 存在 **做种人数 ≥5** 的候选时，在这组中优先选容量最小的，容量相同再选做种更多的；全部不足5人时，优先做种最多的，同做种数再选较小容量。未知容量排在同一比较组的已知容量之后，完全并列保持扫描顺序。
6. 使用页面默认下载器与保存目录。只有明确确认下载任务提交成功，才核对并取消原订阅；结果不明确时保留订阅并记录待核对状态。

“下载任务提交成功”不等于视频文件已下载完成。剧名和集数核验也不能保证识别所有同名误匹配。

## ⚙️ 安装与站点配置

1. 在 Chrome 安装 Tampermonkey，并确认它能在你的 MoviePilot 页面运行脚本。
2. 打开 [moviepilot-unsubscribe.user.js](moviepilot-unsubscribe.user.js)，点击 GitHub 的 **Raw** 查看完整内容。新建 Tampermonkey 脚本，用完整文件替换默认内容。
3. 发布版使用示例地址，**必须修改以下两处**为你自己的地址：

   ```javascript
   // @match        https://moviepilot.example/*
   const HOST = 'moviepilot.example';
   ```

   `@match` 使用实际协议和主机；`HOST` 只填主机及端口，不包含协议或路径。例如站点地址为 `https://moviepilot.example:8920`，应分别填 `https://moviepilot.example:8920/*` 和 `moviepilot.example:8920`。不要改成匹配所有网站。

4. 保存后刷新电视剧订阅页和资源页，只启用一份脚本。确认页面左下方出现 **订阅助手 v2.4.0**。

发布文件不包含个人站点地址、账号、凭据或订阅处理记录。记录和跳过名单保存在使用者当前浏览器的本站数据中。

## ▶️ 按步骤操作

点击面板顶部 **展开／收起**。面板默认收起，各分区也可独立折叠。

| 分区 | 操作 |
| :--- | :--- |
| **1 · 设置范围与跳过名单** | 选择维护模式；跳过名单每行一个完整剧名，自动保存，同名全部季跳过。名称中的逗号不作分隔符。运行中先停止再修改。 |
| **2 · 连接资源页** | 在电视剧订阅页点击一次“打开／绑定资源页”，确认连接后回到订阅页。专用资源页自动连接；手动使用已有资源页时，可在该页展开面板点击连接，只保留一个连接。 |
| **3 · 选择运行方式** | 自由选择“单项试跑”或“批量运行（含下载）”。“预览清单”只读且可选，单项试跑也不是批量运行的前置条件。 |
| **执行结果** | 最近100条关键结果连续显示，包括下载任务提交成功、取消订阅成功、失败或待核对。 |
| **4 · 记录与导出** | 查看、复制记录，下载 CSV / Markdown，或使用“CSV 另存为”选择保存位置。 |

- **Alt+Shift+S**：启动批量任务／停止；**Esc**：停止。快捷键需在工作页使用。
- 完成或停止会保存维护记录并尝试下载 CSV。普通下载的位置由 Chrome 设置决定，可按 **Ctrl+J** 查看；没有下载项时使用“另存为”或复制记录。脚本不会把发起普通下载当成已经写入文件。
- 维护模式允许切去浏览其他 Chrome 网页，运行中不主动抢回焦点。保留两个工作标签页，避免在它们内部手动操作；原电影和旧零进度模式仍在切后台时停止。
- Chrome 冻结/丢弃页面、关闭标签页或电脑休眠仍可能中断。超过五分钟无响应会停止；停止不能撤回已经提交的下载或取消请求。
- 对下载状态不明的条目，先检查下载器，再用“处理待核对项”选择允许重试或仅取消订阅，避免重复提交。

## ✅ 验证范围

- 电影取消功能曾由使用者确认可用。
- 开发时通过浏览器人工走通一次电视剧资源搜索、提交下载、取消订阅流程；这不等于最新版自动流程已在真实环境端到端验证。
- 本地模拟覆盖分类、前100保护、跳过名单、后台不抢焦点、整季过滤、做种门槛与容量比较、下载成功／失败、停止、单项限制及报告查看保存。
- MoviePilot 页面结构变化、站点名称不一致或浏览器策略可能导致停止，需要根据具体错误适配。
